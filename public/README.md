# Carpeta public/

Añade aquí tus assets estáticos reales antes de publicar el sitio, por ejemplo:

- `favicon.ico`
- `og-image.jpg` (1200x630) — usado en Open Graph / redes sociales
- `icon-192.png` y `icon-512.png` — usados en app/manifest.ts (PWA)

Mientras no existan, Next.js simplemente devolverá un 404 para esas rutas de imagen sin romper el build ni el resto del sitio.
